

## 🚀 Project: LLaVA-pp (LLaVA++ Extension)
**Repository:** https://github.com/hectorr-st/LLaVA-pp :contentReference[oaicite:1]{index=1}

### 🧠 Project Summary
LLaVA-pp (also called LLaVA++) enhances the popular LLaVA multimodal model by integrating newer base LLMs such as Phi-3 and LLaMA-3, expanding visual-language capabilities and performance. :contentReference[oaicite:2]{index=2}

### 🛠️ Key Responsibilities
- Implemented and integrated advanced LLM backbones (Phi-3, LLaMA-3) into the LLaVA architecture.
- Adapted model training and evaluation pipelines for extended multimodal support.
- Improved documentation and code structure for community use and reproducibility.
- Collaborated with other contributors on design decisions and performance benchmarks.

### 🏆 Achievements
- Successfully extended LLaVA to support cutting-edge LLMs.
- Optimized workflows for training visual language models with new backbones.
- Contributed code, examples, and improvements enhancing usability for other developers.
